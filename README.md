# blog.lepee.dev

Source of [blog.lepee.dev](https://blog.lepee.dev), built with [Astro](https://astro.build) and deployed to GitHub Pages.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build
```

Posts live in `src/content/blog/`. Illustrations are generated with the `illustration` skill in `.claude/skills/`.
